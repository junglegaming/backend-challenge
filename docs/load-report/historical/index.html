Reproduzir com Bun, sem serviço ou rede

O script acompanha o clone e usa somente Bun e APIs nativas. Forneça os três diretórios com os agregados autorizados e uma pasta de saída nova; nenhum caminho privado de planejamento é default. Nenhum agregado bruto com identificadores precisa ser commitado.

BUN_CONFIG_NO_ENV_FILE=true BUN_CONFIG_NO_AUTO_INSTALL=true bun --no-env-file scripts/render-load-report.ts \
  --aws-quick /caminho/agregados-quick \
  --local-full /caminho/agregados-full-local \
  --aws-full-1 /caminho/agregados-full-aws \
  --output-dir /caminho/novo-relatorio

Os leitores abrem somente result.json, verification.json, environment.json e os quinze nomes literais de fase/counters/prometheus. Os FULL excluídos não têm suas fases abertas. Mistura de fonte/hash é recusada mesmo quando o run seria excluído. HTML/SVG usam conteúdo inline, sem bibliotecas, fontes, scripts ou serviços externos.
