Como ler estes relatórios

Os FULL locais e o FULL AWS pertencem a fontes, instrumentos e recursos diferentes. Não se calcula uma razão de desempenho entre ambientes. Percentis por fase não são somados nem convertidos em um percentil global por média.

Os gráficos usam contagens e séries agregadas, sem payloads financeiros ou identificadores de infraestrutura. campaign.json em cada página nova é uma projeção fechada e versionada: ela permite regenerar o HTML com Bun, sem cache privado, Docker ou AWS.

Passar o FULL comprova os gates daquela execução. Descartes do gerador, amostras ausentes e diferenças de janela impedem inferir que 500 req/s foram sustentados. Os detalhes ficam em metodologia local e resultado AWS.

HTML autossuficiente · SVG inline · JavaScript local apenas para o seletor de tema · sem dependências externas, CDN ou fontes externas. Para navegar no host: docker compose --env-file /dev/null -p wagering up -d --wait docs → http://localhost:4173/docs/load-report/index.html. Alternativa sem Docker: bun run docs:preview. A abertura por file:// exige acesso do navegador à árvore completa de arquivos.
